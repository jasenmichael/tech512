You need custom software when a packaged tool cannot follow your work. The offer is on [Custom software](/custom-software).

## A workflow you do not control

A packaged tool follows steps chosen for many customers. When your steps differ, the tool stops being how the work gets done.

## Facts typed twice

The same facts get typed into a second tool, because the first one cannot pass them on. An application can take that repeat off the desk.

## Which shape fits

A web app fits when the people doing the work can use a browser. Another custom app fits when that work is not a public site.

Automation fits when the repeated task follows a rule you can name. A native app fits when the work has to run on the device.

## When the job is a public site

A public site is a [website](/websites). This application is the wrong tool for that job.
