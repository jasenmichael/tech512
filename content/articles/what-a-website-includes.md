# What a website includes

These are the pieces of a TECH 512 website, in the order they are built. The offer is on [Websites](/websites).

## Page structure

Page structure is which pages exist, and how a visitor moves from one to the next.

## The pages

Each page is built to do one job for the person who lands on it.

## The copy

Copy is the wording on those pages. It tells the right person what you do.

## Metadata

Metadata is the title and the description a search result can show. Each page gets its own.

## Sitemap

A sitemap lists the public pages so a search engine can find them.

## On-page SEO

On-page SEO is the work on the page that helps the right person find it.
